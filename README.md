# Installation

### To install the package, open R and type:


``` r
install.packages("devtools")
```

### Then, you can install TaiwanSSP245:


``` r
devtools::install_github("chihlinwei/TaiwanSSP245", dependencies = TRUE)
library(TaiwanSSP245)
```
